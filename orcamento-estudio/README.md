# Interactive Growth Proposal

A self-contained, browser-based commercial proposal for a beauty studio, combining positioning, acquisition strategy, implementation scope and visual presentation in one interactive artifact.

## Why this project exists

Traditional proposals often separate strategy from execution. This project turns both into a single navigable experience: the client can understand the diagnosis, proposed growth system and delivery scope without switching between slides, documents and mockups.

## What it demonstrates

- Translating a business diagnosis into an implementation narrative
- Information architecture for a long-form commercial document
- Responsive, presentation-grade interface design
- Packaging strategy and technical scope into a decision artifact
- Shipping a zero-install deliverable that works directly in the browser

## Files

- `index.html` — primary entry point
- `proposta-estudio.html` — standalone proposal artifact

Both files are self-contained HTML documents with embedded presentation assets.

## View locally

Open `index.html` directly in a modern browser. No build step or dependency installation is required.

## Position in the portfolio

This is not a reusable SaaS product. It is a focused example of product thinking applied to consulting and commercial communication: turning an ambiguous service conversation into a structured, visually persuasive decision.
